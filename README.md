# GeekForce Hub

Internal career-support workspace for the 4Geeks Academy GeekForce USA team: graduate tracking, a daily job sweep across US job boards, Talent Pipeline shortlists, job-search automations and a weekly research brief.

This version runs on sample data and is not connected to Notion, Slack or any job board yet.

Live page: https://victor4geeksacademy.github.io/geekforce-hub/
